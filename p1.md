## 📄 Official Documentation & References

- [Python 3 Official Documentation](https://docs.python.org/3/) – The definitive and latest language reference from the PSF.
- [Python Tutorial](https://docs.python.org/3/tutorial/index.html) – The official guided tour of the language syntax and standard features.
- [The Python Standard Library](https://docs.python.org/3/library/index.html) – Detailed reference for all built-in modules (math, itertools, datetime, etc.).
- [PEP 8 -- Style Guide for Python Code](https://peps.python.org/pep-0008/) – The essential guide for writing "Pythonic" code.
- [Python Module of the Week (PyMOTW-3)](https://pymotw.com/3/) – Doug Hellmann's excellent guide to the standard library by example.
- [Python Packaging User Guide](https://packaging.python.org/) – The official guide to distributing and installing Python packages.

## 📖 Books (Free)

- [Automate the Boring Stuff with Python](http://automatetheboringstuff.com/chapter0/) – Al Sweigart. Focuses on practical tasks for non-programmers (web scraping, Excel manipulation).
- [Think Python](http://www.greenteapress.com/thinkpython/) – Allen B. Downey. Focuses on computer science logic and the "way of the program."
- [Hitchhiker’s Guide to Python!](http://docs.python-guide.org/en/latest/) – Kenneth Reitz. Best practices for development and production-ready Python.
- [A Byte of Python](https://python.swaroopch.com/) – Swaroop C. H. An excellent, fast-paced introduction for absolute beginners.
- [Dive into Python 3](http://getpython3.com/diveintopython3/) – Mark Pilgrim. Designed for experienced programmers moving to Python.
- [Python Data Science Handbook](https://github.com/jakevdp/PythonDataScienceHandbook) – Jake VanderPlas. Covers NumPy, Pandas, Matplotlib, and Scikit-Learn via Jupyter Notebooks.
- [A Whirlwind Tour of Python](https://jakevdp.github.io/WhirlwindTourOfPython/) – A fast-paced intro to Python for scientists and engineers.
- [Intermediate Python](http://book.pythontips.com/en/latest/index.html) – Yasoob Ullah Khalid. Covers advanced topics like decorators, generators, and mutations.
- [Python for Everybody (PY4E)](http://py4e.com/book.php) – Charles Severance. A great bridge for data analysis and informatics.
- [The Coder's Apprentice](http://www.spronck.net/pythonbook/) – Pieter Spronck. A comprehensive tutorial for Python 3.

## 📖 Books (Paid / Modern)

- [Fluent Python](https://www.amazon.com/gp/product/1491946008) – Luciano Ramalho. Often called the "Bible" for moving from intermediate to advanced Python.
- [Effective Python](https://effectivepython.com/) – Brett Slatkin. 90 specific ways to write better, more performant code.
- [Beyond the Basic Stuff with Python](https://inventwithpython.com/beyond/) – Al Sweigart. Covers professional tools (Git, Linters, Type Hinting) and OOP.
- [The Quick Python Book, 4th Edition](https://shortener.manning.com/1GBV) – Naomi Ceder. A top-tier comprehensive guide (updated for 2025).
- [Learning Python, 5th Edition](https://www.amazon.com/gp/product/1449355730) – Mark Lutz. A massive, deep-dive reference into the core language.
- [Python One-Liners](https://pythononeliners.com/) – Christian Mayer. Focuses on concise, eloquent, and functional code.
- [The Art of Clean Code](https://nostarch.com/art-clean-code) – Christian Mayer. Focuses on complexity management and readability.

## 🧰 Tools, IDEs & Linters

- [Thonny](https://thonny.org/) – The best IDE for absolute beginners (includes variable visualization).
- [PyCharm](https://www.jetbrains.com/pycharm/) – A professional-grade, full-featured IDE.
- [VS Code (Python Extension)](https://code.visualstudio.com/docs/languages/python) – The most popular general-purpose editor for Python.
- [Black](https://black.readthedocs.io/) – The uncompromising code formatter.
- [Ruff](https://docs.astral.sh/ruff/) – An extremely fast Python linter and formatter (replaces Flake8/isort).
- [Python Tutor](https://pythontutor.com/) – Visualize how your code runs step-by-step.
- [mypy](https://mypy.readthedocs.io/) – Static type checker for optional static typing.
